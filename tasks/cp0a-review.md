## Review findings and deliberate limits

- Correctness: fixed fallback duplication and WebKit skip focus; no known failing local acceptance test remains. Unimplemented scripts fail loudly. Boundary docs do not turn future service names into fabricated SDK calls.
- Architecture/readability: no decorators, state framework, backend, storage, router/gameplay or PG work added early. Root light DOM is documented. No direct main-thread PGlite/parser import; a 17.13 kB Lit app chunk is the largest runtime file.
- Security: escaped Lit bindings, no user data collection/secrets, production bundle excludes installed PG/parser. `npm audit fix --force` was not used. The explicit `minimatch@11.0.3` override crosses consumer major ranges and is the notable dependency risk to review; current type/lint/unit/negative checks and clean audit pass. Retest/remove it when upstream supports the patch.
- Performance: shell assets are small and same-origin; no game-performance or cold PG boot claim. No benchmark on real devices was fabricated.
- Visual/keyboard review: desktop and 360px dark/light images inspected for readable text, hierarchy, spacing and overflow. Keyboard sequence exercised in real browser engines via Playwright; not called a human screen-reader audit. Screenshot baselines are Windows/Chromium-specific; hosted Windows fonts may still need a reviewed CI-specific adjustment rather than tolerance inflation.
- Real Ubuntu/Nginx HTTPS, PG18/AST/editor/PWA, iOS/Android/AT and participant findings remain **future gates**, not failed CP0a implementations. Owner follow-ups are in `tasks/owner-actions.md`.
- Existing Graphify artifacts remain the previously committed planning navigation map, not an updated application dependency graph. No commit hook ran; consult current source and these boundary docs for implemented code.
