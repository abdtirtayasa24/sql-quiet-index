## Trust boundaries / constraints

- Worker messages are untrusted; require session/request IDs, runtime payload guards and bounded SQL. Client ignores stale or mismatched replies and rejects on termination/error/deadline. Only fixed probe SQL executes until later safety work.
- AST recognition is not a read-only allowlist. Explicitly demonstrate that top-level SELECT can contain modifying CTEs and multiple statements; no regex general parser or claim of grading safety.
- CodeMirror sees only explicitly visible table/column metadata. Native fallback preserves the current editing state and announces the switch. No storage guarantee before T10–T14.
- Package/file checksums are recorded independently of the verifier; never regenerate a baseline inside verification. Unknown/missing artifacts, license drift and checksum mismatch fail.
- Test the restrictive spec CSP locally without broad `unsafe-inline`/`unsafe-eval`; record a blocker/ADR if injected editor styles cannot satisfy it. Local preview CSP is not deployed Nginx evidence.

## Review findings / residual risks

- **Correctness:** scope is fixed PG probes + parser inspection + editable draft, not a query REPL or safe grader. Tests inspect actual results/paths, not answer text alone. Unknown/oversize messages fail; stale replies do not resolve promises. Rich/native switches retain in-page draft, selection and undo/redo; reconnect and missing-worker recovery are covered.
- **Architecture/readability:** no runtime server, state framework, persistence, service worker, mission data or gameplay added. Pure editor model and engine protocol stay separate from Lit rendering; worker owns the only PGlite construction. CodeMirror remains a typed mount/reconfigure/destroy adapter. No vendor SDK methods were guessed.
- **Supply chain:** the audit found old lock records lacking registry integrity metadata. Regenerated the lock with npm in an isolated cache project, verified **no pre-existing package/version identity was removed/upgraded**, then clean-installed. Larger lock diff includes metadata completion and dependency hoisting, plus explicitly approved CM/type additions. No manual lock editing or forced audit downgrade.
- **Licensing:** selected vendor hashes and packaged notices are verified. The SSR DOM shim package omits standalone license text; declared BSD metadata and that absence are recorded in the inventory/notices. This is not a full legal/source-component license certificate; complete that release follow-up before public distribution.
- **Security:** user input never reaches PostgreSQL execution in this spike. Local worker/document CSP retains self-only script/style/worker/connect with `wasm-unsafe-eval` only. The parser transform is exact and fail-closed; no broad unsafe-inline/eval or runtime CDN. No sensitive data, telemetry or credentials introduced. Future AST allowlist/result canonicalization/query sandboxing remain T22–T25, not implied by parse success.
- **Performance:** engine/parser assets remain opt-in on the separate proof page; no real-device P75, memory envelope, snapshot benefit or offline readiness claim. Raw/gzip file sizes are not wire benchmarks. Generated PG fallback chunks/eval warnings remain visible and need re-audit on upgrades.
- **Visual/a11y:** four new images inspected; legible hierarchy, wrapping, editor/button spacing, both themes and no page overflow at 360px. Built axe/keyboard checks pass. The owner reports Android Chrome and Windows functional success on the deployed proof; detailed AT/IME/clipboard sequences and Safari/iOS remain unreported. Hosted response CSP/nosniff are missing. These remaining criteria were not marked passed.
- **Git/operations:** the owner now authorizes the CP0b local commit, but not a push or T08+. The owner-operated Cloudflare proof is recorded without changing the selected Ubuntu/Nginx production architecture. The agent performed read-only HTTP inspection only; no deployment, DNS/firewall/TLS or global configuration changes. Original specifications and LICENSE remain unchanged.
